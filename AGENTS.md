# Fred plugin

This independent public repository owns Fred. Follow README.md and docs/DESIGN.md.

- Exactly three skills: fred, characters, combat. This is a self-contained text plugin.
- Preserve source wording and page order in sources/srd/. Navigation belongs in separate indexes.
- Never import purchased-book material, private catalogs, local paths or campaign saves.
- MIT applies to our original work; SRD and DPCGL text retain their own terms.
- Run python3 scripts/build.py and python3 scripts/validate.py after changes.
- Gameplay evidence must come from the installed plugin; distinguish tests from manual examples.
- No hosted service or directory submission in version one.
